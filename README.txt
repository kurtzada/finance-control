FINANCE CONTROL — PWA

Arquivos:
- index.html: aplicativo
- manifest.webmanifest: instalação PWA
- sw.js: funcionamento offline
- icon-*.png: ícones

No iPhone:
1) Hospede a pasta em um endereço HTTPS.
2) Abra no Safari.
3) Compartilhar > Adicionar à Tela de Início.
4) Abra pelo ícone.

Os dados são salvos no armazenamento do navegador do aparelho.
Use Exportar dentro do app para ter um backup JSON.
